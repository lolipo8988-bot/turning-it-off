# Have You Tried Turning It Off?

A make.fun program/v1 entry for the bounty
[Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b):
one funny single-line reply from a hopeless tech support agent to a
desperate customer.

## The entry

> Have you tried turning it off and on again? No? Perfect — that's step one of my entire training, and step two is asking you to do it again.

The joke twists the classic restart line: the agent's entire training
is just that one question, asked on a loop. His cheerful uselessness
is the humour — the customer is never the butt of it.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-turning-it-off python3 main.py
cat /tmp/out-turning-it-off/entry.txt
```

`main.py` (Python 3, no dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The
output is a single line of 139 characters, inside the gate's 1–199
character limit.
